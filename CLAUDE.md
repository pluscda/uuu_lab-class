## Hard Constraints (never change)

- API binds `127.0.0.1:5000` — do **not** switch to `localhost` (Docker Desktop occupies the IPv6 port).
- Only .NET SDK 10 is installed; projects keep `<TargetFramework>net9.0</TargetFramework>` + `<RollForward>LatestMajor</RollForward>`.
- PrimeNG **20** — do **not** upgrade to PrimeNG 21.
- Dapper only — no Entity Framework.
- DB: local `SQLEXPRESS`, database `CMS`, `Trusted_Connection=True`; connection string in `src/CMS.API/appsettings.json`.

## Convention Quick Reference

Details and examples in `spec/code-gen.convention.md` — the rules below are the invariants:

- Per table: `Models/{Entity,EntityRequest,EntityQuery}.cs`, `Repositories/I{Entity}Repository.cs` + impl (Scoped; `IDbConnectionFactory` Singleton), `Controllers/{Entities}Controller.cs`; async; transactions for multi-writes.
- Routes: kebab-case plural (`/api/app-roles`); PUT updates via body; POST → **409** on duplicate key; lookups at `/api/lookups/{plural}`.
- N-N: delete-then-reinsert; counts via subquery; ID lists populated on GET-by-id only.
- Angular: `features/{plural}/{entity}-{list|detail|form}/` (each `.ts/.html/.scss/.spec.ts`); services `core/services/`, models `core/models/`; always `environment.apiUrl`; `encodeURIComponent()` for string IDs.
- Dates: SQL `date` → `DateOnly` (Dapper handler in `Data/`, registered in `Program.cs`); frontend `core/utils/date.util.ts` — `toIso()` uses local components, never `toISOString()`.
