Full-stack CMS generated from the SQL Server schemas in `database/*.sql`
(auth, admin, course, promotion).

## Reference Files (read when relevant — details live there, not here)

- `spec/code-gen.convention.md` — **all** coding conventions: backend
  (models/repos/controllers, routes, N-N, special types), frontend (list/form
  pages, theme, sidebar, unit tests), date handling.
  **Read before generating or modifying feature code.**
- `spec/status.md` — completed modules + entity gotchas, lookup endpoints,
  sidebar groups, test counts, remaining work.
  **Read before planning a module; update after finishing one.**
- `spec/{sub-system}/{Table}.md` — per-entity feature specs generated by `/crud`
  (reviewed before build).
- `spec/ui-sample-*.png` — UI style reference. Visual style only; never copy content.

## Structure

`src/CMS.slnx` solution (.NET SDK 10 format) · `src/CMS.API` .NET 9 Web API +
Dapper · `src/CMS.API.Tests` xUnit + Moq · `src/CMS.NG` Angular 20 + PrimeNG 20

## Commands

- API: `cd src/CMS.API && dotnet run` → http://127.0.0.1:5000 (Swagger `/swagger`)
- Backend tests: `cd src && dotnet test CMS.slnx`
- Frontend: `cd src/CMS.NG && npm start` → http://localhost:4200
- Frontend tests / build: `ng test --watch=false --browsers=ChromeHeadless` / `ng build`

## Auth (details in `spec/status.md`)

- Every API endpoint requires a JWT Bearer token except `POST /api/auth/login`
  (global FallbackPolicy; only the `Login` action is `[AllowAnonymous]`).
  Swagger/manual calls need an `Authorization: Bearer` header too.
- Token signed AND validated with SysConfig `appConfig.symmetricSecurityKey`
  (read from DB at runtime, never from appsettings).
- Frontend: `/login` page; profile + token in **session** storage (`auth-profile`);
  `authInterceptor` adds the Bearer header, any 401 → clear session → `/login`;
  `authGuard` protects all routes; `系統管理 Admin` sidebar group only for role `Admin`.
- Dev login: `miles@uuu.com.tw` / `CMS4fun#` (= SysConfig `appConfig.defaultPassword`;
  login hash = SHA-256 UTF-8 uppercase hex).

## Hard Constraints (never change)

- API binds `127.0.0.1:5000` — never `localhost` (Docker Desktop holds the IPv6 port).
- Only .NET SDK 10 installed; projects keep `net9.0` + `<RollForward>LatestMajor</RollForward>`.
- PrimeNG **20** — never upgrade to 21.
- Dapper only — no Entity Framework.
- DB: local `SQLEXPRESS`, database `CMS`, `Trusted_Connection=True`;
  connection string in `src/CMS.API/appsettings.json`.
